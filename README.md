# Mail Hub (纯本地跨平台桌面邮箱管理器)

基于 **Electron 30 + React 18 + TypeScript + Ant Design 5 + Tiptap** 纯本地重构的跨平台桌面应用。**独立原生窗口运行（非网页），数据 100% 保存在本地电脑，完美支持 Windows 与 macOS！**

---

## 🌟 核心功能一览

1. **统一发件与收件配置 (SMTP & IMAP)**
   - 快捷预设填充主流邮箱参数（QQ邮箱、163网易、Gmail、腾讯企业邮、阿里企业邮等）。
   - **双向真实连通性测试**：一键发送测试邮件测试 SMTP 发信，一键验证 IMAP 登录。
   - **每日配额防封**：设置单日最大发信量，跨天自动清零，超限自动熔断切换其他发件箱。

2. **多邮箱智能分摊群发 (核心调度引擎)**
   - 勾选多个可用邮箱，引擎自动按**轮询（Round-Robin）算法**在勾选的邮箱之间均衡分摊发送任务。
   - 某一邮箱达限或报错时，自动无感切换至下一可用邮箱。
   - **防风控抖动延时**：自由设置发送间隔（如 2~5 秒随机浮动），模拟真人发送行为。

3. **收件箱与一键快捷回复 (Inbox & Reply)**
   - 多邮箱聚合收取邮件，支持按指定邮箱筛选。
   - **只读协议保护**：采用 IMAP 只读模式收取，不改变您在其他客户端的已读状态。
   - **一键快捷回复**：阅读邮件时一键点击“回复”，系统自动带入发件人、生成 `Re: 主题` 并自动引用原邮件正文，挑选任意发件箱即可直接发出。

4. **单封即时发送 (Single Send)**
   - 自由挑选发件箱，直接撰写富文本并即时精准发出。

5. **所见即所得富文本编辑 (Tiptap Rich Editor)**
   - 标题、加粗、斜体、删除线、列表、超链接、图片与 HTML 源码双向查看。
   - **动态变量个性化插值**：支持插入 `{name}`（收件人称呼）、`{email}`（收件人邮箱）、`{date}`（当前日期）、`{datetime}` 等，发送时自动替换。

6. **联系人与大文本批量导入**
   - 群组分类管理，支持大文本直接粘贴批量导入（自动识别 `abc@qq.com`、`张三,zhangsan@domain.com`、`李四 <lisi@test.com>` 并自动去重）。

7. **任务调度大厅与明细监控**
   - 实时进度条与成功/失败数统计，支持**随时暂停、恢复、终止**。
   - 逐封邮件明细日志：清晰记录每封邮件分别是由**哪个发件箱**发出的、发送时间、状态及具体报错信息。

## 🚀 本地开发与启动

在项目根目录下：

### 1. 启动桌面应用开发环境
```bash
npm run dev
```
> Vite 会同时编译 Electron 主进程与渲染进程，并**自动弹出原生的桌面应用程序窗口**，支持热重载（HMR）！

## 📦 打包生成 Windows / macOS 安装包

本项目使用纯 JS/TS 方案（nodemailer + imapflow + mailparser），**零 C++ 原生编译依赖**，无论是 Mac 还是 Windows 均可秒级一键打包！

### 打包 Windows 版本 (.exe)
```bash
npm run build:win
```
> 将在 `release/` 目录下生成：
> - **Windows 安装包**：`MailHub Setup 1.0.0.exe` (支持自定义安装目录、自动生成桌面快捷方式)
> - **免安装便携绿色版**：`MailHub 1.0.0.exe` (双击即用)

### 打包 macOS 版本 (.dmg / .app)
```bash
npm run build:mac
```
> 将在 `release/` 目录下生成 macOS 的 `.dmg` 安装镜像与可执行程序。

## 💾 本地数据存储位置

所有发件箱账号、收件邮件、联系人、模板与发送流水日志完全保存在本地，不经过任何云端服务器：
- **Windows**：`%APPDATA%\mail-hub-desktop\mail_hub_data.json`
- **macOS**：`~/Library/Application Support/mail-hub-desktop/mail_hub_data.json`
